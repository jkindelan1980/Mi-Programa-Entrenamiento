El nombre del ejercicio se convierte en un acceso directo al vídeo cuando introduces una dirección web. Los vídeos necesitan conexión a Internet; el resto funciona sin conexión.

Cómo funciona

Todo se guarda en este navegador. Abre siempre el mismo archivo con Chrome o Edge en este ordenador. Guarda periódicamente una copia de seguridad en formato JSON para no depender únicamente del navegador.
  1. En el calendario, pulsa Entreno A, B, C o D.
  2. Marca el ejercicio al acabar y registra repeticiones y kilos de cada serie.
  3. Pulsa el nombre o “Vídeo” para abrir la demostración, cuando exista enlace.
  4. Usa el lápiz “Editar” para cambiar ejercicio, series, tempo, descanso o vídeo.
  5. Imprime el plan completo o únicamente la sesión abierta.
  6. La opción “Copiar a semanas siguientes” replica la prescripción, pero deja las marcas en blanco.
